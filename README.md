# 마이 라이프 트래커

일상생활의 운동과 지출을 추적하고 시각화하는 웹 애플리케이션입니다.

## 기능

- 유산소 운동 거리 및 시간 기록
- 실외 러닝 여부 체크
- 근력 운동 시간 기록
- 일일 지출 금액 기록
- 날짜별 데이터 입력 및 수정
- 최근 7일간의 운동 및 지출 꺾은선 그래프
- 주간 통계 요약

## 사용 방법

1. 캘린더를 통해 원하는 날짜 선택
2. 해당 날짜의 운동 및 지출 데이터 입력
3. 저장 버튼을 클릭하여 데이터 저장
4. 차트와 통계 확인

## 데이터 저장

모든 데이터는 브라우저의 localStorage에 저장되며, 별도의 서버 연결 없이 작동합니다.

## 기술 스택

- HTML5
- CSS3
- JavaScript (바닐라)
- Chart.js (그래프 시각화)
